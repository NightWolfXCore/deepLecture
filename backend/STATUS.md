Срез на 28 октября 2026, ветка `backend`. Основание — PDF

## Реализация и оставшиеся функции

| Требование | Наша реализация | Что ещё подтвердить или реализовать |
|---|---|---|
| MP4/WebM, уникальный ID, хранение | PHP multipart API, UUID, файловое хранилище, очередь MySQL | Проверить демонстрационную лекцию на целевом компьютере |
| YouTube/Vimeo | API импорта, очередь, yt-dlp/Deno, лимиты, FFmpeg, публикация под lease | Реальное скачивание с платформ не подтверждено; тесты загрузчика используют подмену источника |
| Аудиодорожка | FFmpeg/ffprobe, PCM mono 16 kHz | Настоящий FFmpeg проверен на сгенерированных MP4/WebM; это не проверка речи |
| Транскрипт и время | faster-whisper, start_ms/end_ms, ограничение длительностью видео | Настоящий Whisper на речи не проверен; миллисекунды хранения не гарантируют точность ASR до секунды |
| Семантический индекс | multilingual-e5-small, 384 нормализованных float32, ревизия рядом с вектором | Настоящие E5-векторы и смысловая релевантность не проверены |
| Поиск, текст, таймкод, переход | PHP → внутренний FastAPI → NumPy/MySQL; текст, start_ms/end_ms, playback_url | Интеграционные проверки используют детерминированный encoder; реальный поиск и скорость требуют лекции |
| Плеер, синхронные субтитры, клики | API транскрипта и медиа Range/HEAD подготовлены; код UI опубликован участником | Подключение UI и реального API проверено; воспроизведение/перемотка/подсветка в браузере ещё не проверены |
| Конспект, разделы/подразделы | OpenAI-compatible адаптер, пакетная обработка, level 1/2, проверка start_segment_id | Реальная LLM и качество конспекта не проверены; вымышленные ID отклоняются |
| Оглавление с переходами | API отдаёт главы с временем существующего сегмента; UI содержит обработчики | Проверить поведение в браузере на лекции |
| Поиск по курсу | Реализован по всем готовым индексам при отсутствии lecture_id | Протокол и изоляция проверены, смысловая релевантность требует настоящего E5 |
| Чат вопрос–ответ | RAG по выбранной лекции, проверка источников и актуальности индекса | HTTP и LLM-адаптер проверены с подменами; реальная Qwen не подтверждена |
| Ключевые термины | Частотный/фразовый алгоритм и упоминания из транскрипта | Определения — исходные фрагменты, качество выделения требует просмотра лекции |
| Офлайн | Локальный Qwen3.5 4B через Ollama, cache-only ASR/E5, отдельный override сети | Конфигурация подготовлена; веса, inference и полный запуск без интернета не подтверждены |
| Стабильность | MySQL lease/heartbeat, восстановление, fencing, атомарные этапы и retry, health/readiness | Настоящие модели и длительная нагрузка на целевом оборудовании не проверены |

## Модели и границы доказательств

В этой облачной среде запросы к `huggingface.co` и `registry.ollama.ai`
получили `Tunnel connection failed: 403 Forbidden`. TLS-проверка не отключалась.
Ключ внешнего LLM API не предоставлен. Квоты бесплатных провайдеров не проверены.

Целевая локальная модель изменена по запросу пользователя на `qwen3.5:4b`.
Образ Ollama обновлён с 0.6.8 на 0.40.12; существование Docker manifest
и поддержка reasoning_effort в исходниках этой версии проверены. Для конспектов
задаётся `reasoning_effort=none`. Это не подтверждает скачивание тега модели,
квантизацию, скорость или реальный inference. Q4_K_M и digest проверяются после
доступного `ollama pull` через `ollama show`.

Для локального GGUF добавлены read-only mounts и Modelfile:
[пошаговый импорт](GGUF.md). Объединённая Compose-конфигурация проверена,
исходный GGUF исключён из Git и build-контекста. Без файла пользователя
реальный импорт и его квантизация остаются неподтверждёнными.

Полная инструкция: [LLM.md](LLM.md). Рабочие `.env` не перезаписываются,
секреты в шаблоны не входят. Установка Ollama на хост не нужна: Compose
скачивает готовый серверный образ, веса отдельно сохраняются в volume.

   распознавания, попадание минимум трёх таймкодов в речь, смысловые запросы

4. Выполнить полный сценарий с новым видео при отключённом интернете и
   заранее подготовленных весах, образах, зависимостях и локальных UI-ресурсах.
5. Подготовить презентацию со скриншотами работающего проекта: проблема,
   решение, демонстрация, технологии и планы. Репозиторий и инструкция запуска
   уже есть; презентация и живая демонстрация всей системы ещё не подтверждены.
